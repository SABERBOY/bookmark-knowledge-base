## [Marks Plot doesn’t have chart types. Instead, it has layered geometric shapes such as bars, dots, and lines.](https://observablehq.github.io/plot/features/marks)

## [Scales Scales map an abstract value such as time or temperature to a visual value such as position or color.](https://observablehq.github.io/plot/features/scales)

## [Transforms Derive data on-the-fly while plotting, say to bin quantitative values or compute a rolling average.](https://observablehq.github.io/plot/features/transforms)

## [Facets Small multiples facilitate comparison by repeating a plot across partitions of data.](https://observablehq.github.io/plot/features/facets)

## [Projections Plot supports GeoJSON and D3’s spherical projection system for geographic maps.](https://observablehq.github.io/plot/features/projections)

## [Built with D3 Plot is built by the same team as D3. If you know some D3, you’ll be right at home with Plot. Visit D3](https://d3js.org/)

## [Plot without code With Observable’s chart cell, quickly create plots with a GUI, then eject to code to customize. Try chart cell](https://observablehq.com/@observablehq/chart-cell)
