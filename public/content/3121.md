## 二、任务生命周期

```
1. TaskManager 初始化
2.   → 读取 GamePartConfig 配置
3.   → 遍历任务线，创建任务实例
4.       → Task:Init(TaskID, self)         设置 self.TaskID, self.Owner = TaskManager
5.       → Task:BeginPlay()                Lua 层绑定事件、启动定时器
6.           ... 任务运行中 ...
7.           → self.Owner:UpdateTaskProgressByID(self.TaskID, PC, Progress, IsIncremental)
8.   → TaskManager 结束
9.      → Task:EndPlay()           Lua 层解绑事件、清理定时器
```

## 三、任务分类体系

系统预定义了 **4 类任务** ，在创建蓝图时需选择对应父类：

| 分类 | 蓝图父类 | 用途 |
| --- | --- | --- |
| 攻击 | `UGCAttackTask` | 击杀、伤害等战斗目标 |
| 评价 | `UGCEvaluationTask` | 排名、评分等竞赛目标 |
| 道具 | `UGCItemTask` | 获取、消耗物品目标 |
| 系统 | `UGCSystemTask` | 在线时长、任务线进度等 |

这些父类仅做类型区分，无额外逻辑。真正行为在 **Lua 层** 或 **蓝图层** 实现。

## 五、进度更新方式

核心 API：

```
self.Owner:UpdateTaskProgressByID(TaskID, PlayerController, Progress, IsIncremental)
```

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `TaskID` | number | `self.TaskID` ，由 Init 注入 |
| `PlayerController` | APlayerController | 目标玩家的 PC |
| `Progress` | number | 进度值 |
| `IsIncremental` | boolean/nil | `true` = 累加，`nil/false` = 直接设置 |

### 使用场景

| 场景 | 调用方式 |
| --- | --- |
| 击杀 +1 | `self.Owner:UpdateTaskProgressByID(self.TaskID, PC, 1, true)` |
| 伤害 +N | `self.Owner:UpdateTaskProgressByID(self.TaskID, PC, math.floor(Damage), true)` |
| 排名直接设 | `self.Owner:UpdateTaskProgressByID(self.TaskID, PC, Rank)` |
| 任务线进度 | `self.Owner:UpdateTaskProgressByID(self.TaskID, PC, Progress)` |

### PlayerKey → PlayerController 转换

```
local PC = UGCGameSystem.GetPlayerControllerByPlayerKey(PlayerKey)
if not UE.IsValid(PC) then return end
```

## 十二、自定义任务实战 — 完整示例

### 示例1：累计使用技能次数任务

**场景** ：玩家累计使用指定技能 N 次完成任务。

**Lua 代码** （放于 `ugc/UGCGame/Task/AttackTask/BP_UGCCumulativeSkillUseTask.lua` ）：

```
local BP_UGCCumulativeSkillUseTask = {};

function BP_UGCCumulativeSkillUseTask:BeginPlay()
    print_dev("[BP_UGCCumulativeSkillUseTask:BeginPlay]")
    if not UE.IsValid(self.Owner) then return end
    if not self.Owner:HasAuthority() then return end

    -- 监听技能使用消息（需确认实际消息路径）
    GMP.GlobalMessage.BindUObject(self, "UGC.PlayerPawn.SkillUsed", self, self.OnSkillUsed)
end

function BP_UGCCumulativeSkillUseTask:EndPlay()
    if not UE.IsValid(self.Owner) then return end
    if not self.Owner:HasAuthority() then return end
    GMP.GlobalMessage.UnBindUObject(self, "UGC.PlayerPawn.SkillUsed", self)
end

function BP_UGCCumulativeSkillUseTask:OnSkillUsed(PlayerKey, SkillID)
    if not UE.IsValid(self.Owner) then return end
    -- 校验技能ID是否匹配（SkillID 为蓝图属性）
    if self.SkillID and SkillID ~= self.SkillID then return end
    local PC = UGCGameSystem.GetPlayerControllerByPlayerKey(PlayerKey)
    if not UE.IsValid(PC) then return end
    self.Owner:UpdateTaskProgressByID(self.TaskID, PC, 1, true)
end

return BP_UGCCumulativeSkillUseTask
```

**蓝图侧** ：创建 `BP_UGCCumulativeSkillUseTask` 蓝图（父类 `UGCAttackTask` ），添加变量：

*   `TaskID` (int32)
*   `SkillID` (int32) — 目标技能ID，0 表示不限

### 示例2：区域停留时长任务

**场景** ：玩家在指定区域累计停留 N 分钟。

**Lua 代码** （放于 `ugc/UGCGame/Task/SystemTask/BP_UGCAreaStayTimeTask.lua` ）：

```
local BP_UGCAreaStayTimeTask = {}

function BP_UGCAreaStayTimeTask:BeginPlay()
    print_dev("[BP_UGCAreaStayTimeTask:BeginPlay]")
    if not UE.IsValid(self.Owner) then return end
    if not self.Owner:HasAuthority() then return end

    self.PlayerEnterTime = {}

    -- 监听玩家进出区域（自定义消息）
    GMP.GlobalMessage.BindUObject(self, "UGC.CustomArea.PlayerEnter", self, self.OnPlayerEnterArea)
    GMP.GlobalMessage.BindUObject(self, "UGC.CustomArea.PlayerExit", self, self.OnPlayerExitArea)

    -- 每秒检查
    self.Timer = Timer.InsertTimer(1, function()
        local CurTime = UGCGameSystem.GetServerTimeSec()
        for PlayerKey, EnterTime in pairs(self.PlayerEnterTime) do
            if CurTime - EnterTime >= 60 then  -- 每60秒 +1
                self:AddStayTime(PlayerKey)
                self.PlayerEnterTime[PlayerKey] = CurTime
            end
        end
    end, true, "AreaStayTimer")
end

function BP_UGCAreaStayTimeTask:EndPlay()
    if self.Timer ~= nil then
        Timer.RemoveTimer(self.Timer)
        self.Timer = nil
    end
    if not UE.IsValid(self.Owner) then return end
    if not self.Owner:HasAuthority() then return end
    GMP.GlobalMessage.UnBindUObject(self, "UGC.CustomArea.PlayerEnter", self)
    GMP.GlobalMessage.UnBindUObject(self, "UGC.CustomArea.PlayerExit", self)
end

function BP_UGCAreaStayTimeTask:OnPlayerEnterArea(PlayerKey, AreaID)
    if self.AreaID and AreaID ~= self.AreaID then return end
    self.PlayerEnterTime[PlayerKey] = UGCGameSystem.GetServerTimeSec()
end

function BP_UGCAreaStayTimeTask:OnPlayerExitArea(PlayerKey, AreaID)
    self.PlayerEnterTime[PlayerKey] = nil
end

function BP_UGCAreaStayTimeTask:AddStayTime(PlayerKey)
    if not UE.IsValid(self.Owner) then return end
    local PC = UGCGameSystem.GetPlayerControllerByPlayerKey(PlayerKey)
    if not UE.IsValid(PC) then return end
    self.Owner:UpdateTaskProgressByID(self.TaskID, PC, 1, true)
end

function BP_UGCAreaStayTimeTask:ResetTaskForPlayer(PlayerKey)
    self.PlayerEnterTime[PlayerKey] = UGCGameSystem.GetServerTimeSec()
end

return BP_UGCAreaStayTimeTask
```
