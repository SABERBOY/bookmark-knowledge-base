**R**2026**b**

调整图像大小

## 描述

`B = imresize(A,scale)` 返回图像 `B`，它是将 `A` 的长宽大小缩放图像 `scale` 倍之后的图像。输入图像 `A` 可以是灰度图像、RGB 图像、二值图像或分类图像。

如果 `A` 有两个以上维度，则 `imresize` 只调整前两个维度的大小。如果 `scale` 介于 0 和 1 之间，则 `B` 小于 `A`。如果 `scale` 大于 1，则 `B` 大于 `A`。默认情况下，`imresize` 使用双三次插值。

[示例](https://ww2.mathworks.cn/help/matlab/ref/imresize.html#mw_7f1dd55c-032d-4e1a-bb52-dcaae33f3855)

`B = imresize(A,[numrows numcols])` 返回图像 `B`，其行数和列数由二元素向量 `[numrows numcols]` 指定。

[示例](https://ww2.mathworks.cn/help/matlab/ref/imresize.html#mw_3950c5b7-6bfa-43ff-a7a7-acc32b3ac93f)

`[Y,newmap] = imresize(X,map,___)` 调整索引图像 `X` 的大小，其中 `map` 是与该图像关联的颜色图。

[示例](https://ww2.mathworks.cn/help/matlab/ref/imresize.html#mw_3957e4e8-42f0-4156-82e2-822a8241b143)

`___ = imresize(___,method)` 指定使用的插值方法。

[示例](https://ww2.mathworks.cn/help/matlab/ref/imresize.html#mw_0a904a96-3d99-4878-b28f-cdf6f0d7ca0c)

`___ = imresize(___,Name=Value)` 返回调整大小后的图像，其中名称-值参量控制大小调整操作的各个方面。在所有其他输入参量之后指定名称-值参量。

## 输入参数

全部折叠

要调整大小的图像，指定为任意维度的数值数组、逻辑数组或分类数组。输入必须为非稀疏的，数值输入必须为实数。

**数据类型:**`single` | `double` | `int8` | `int16` | `int32` | `uint8` | `uint16` | `uint32` | `logical` | `categorical`

大小调整因子，指定为正数。`imresize` 对行和列维度应用相同的缩放因子。要对每个维度应用不同的大小调整因子，请使用 [`Scale`](https://ww2.mathworks.cn/help/matlab/ref/imresize.html#mw_6ca6cd3c-2b9e-479d-894b-2550355a33ba) 名称-值参量。

如果您指定的大小调整因子不会产生整数长度的图像维度，则 `imresize` 会在调整大小操作后调用 [`ceil`](https://ww2.mathworks.cn/help/matlab/ref/double.ceil.html) 函数。换句话说，输出图像有 `ceil(scale*size(A,1))` 行和 `ceil(scale*size(A,2))` 列。

**数据类型:**`single` | `double` | `int8` | `int16` | `int32` | `int64` | `uint8` | `uint16` | `uint32` | `uint64`

输出图像的行和列维度，指定为由正数组成的二元素向量。您可以为 `numrows` 或 `numcols` 指定 `NaN` 值。在这种情况下，`imresize` 会自动计算该维度的行数或列数，同时保持图像的纵横比。

**数据类型:**`single` | `double` | `int8` | `int16` | `int32` | `int64` | `uint8` | `uint16` | `uint32` | `uint64`

要调整大小的索引图像，指定为由正整数组成的实数非稀疏数值数组。

**数据类型:**`double` | `uint8` | `uint16`

与索引图像 [`X`](https://ww2.mathworks.cn/help/matlab/ref/imresize.html#d127e789034) 相关联的颜色图，指定为由范围 [0, 1] 内的值组成的 _c_×3 数值矩阵。每行是一个三元素 RGB 三元组，指定颜色图的单个颜色的红、绿和蓝分量。

**数据类型:**`double`

插值方法，指定为字符向量、字符串标量或二元素元胞数组。数值图像和逻辑图像的默认值为 `"bicubic"`。分类图像的默认值为 `"nearest"`。分类图像仅支持值 `"nearest"` 和 `"box"`。

| 方法 | 描述 |
| --- | --- |
| `"nearest"`（或 `"box"`） | 最近邻点插值，使用盒形插值核执行。赋给输出像素的值就是其输入点所在像素的值。不考虑其他像素。 |
| `"bilinear"`（或 `"triangle"`） | 双线性插值，使用三角形插值核执行。输出像素值是最近 2×2 邻域中像素的加权平均值。 |
| `"bicubic"`（或 `"cubic"`） | 双三次插值，使用分段三次插值核执行。输出像素值是最近 4×4 邻域中像素的加权平均值。 **注意** 双三次插值可能生成在原始范围之外的像素值。 |
| `"lanczos2"` | 使用 Lanczos-2 核的插值。 |
| `"lanczos3"` | 使用 Lanczos-3 核的插值。 |
| 二元素元胞数组 | 使用自定义插值核的插值。 以 {_f_,_w_} 形式指定元胞数组，其中 _f_ 是自定义插值核的函数句柄，_w_ 是自定义核的宽度。_f_(_x_) 在区间 -_w_/2 <= _x_<_w_/2 外的值必须为零。函数句柄 _f_ 可通过标量或向量输入进行调用。 **注意** 对于用户指定的插值核，输出图像可以有一些值稍微超出输入图像中的像素值范围。 |

有关内置和自定义插值核的详细信息，请参阅[Create and Compare Resizing Interpolation Kernels](https://ww2.mathworks.cn/help/matlab/creating_plots/create-and-compare-resizing-interpolation-kernels.html)。

**数据类型:**`char` | `string` | `cell`

## 名称-值参数

全部折叠

将可选参量对组指定为 `Name1=Value1,...,NameN=ValueN`，其中 `Name` 是参量名称，`Value` 是对应的值。名称-值参量必须出现在其他参量之后，但对各个参量对组的顺序没有要求。

**示例:**`B = imresize(A,0.5,Antialiasing=false)` 在缩小图像时不执行抗锯齿操作。

_如果使用的是 R2021a 之前的版本，请使用逗号分隔每个名称和值，并用引号将_`Name`_引起来。_

**示例:**`B = imresize(A,0.5,"Antialiasing",false)` 在缩小图像时不执行抗锯齿操作。

缩小图像时执行抗锯齿操作，指定为 `true` 或 `false`。

*   如果插值 [`method`](https://ww2.mathworks.cn/help/matlab/ref/imresize.html#d127e789090) 为 `"nearest"`，则 `Antialiasing` 的默认值为 `false`。

*   如果插值 `method` 为 `"box"`，并且输入图像是分类图像，则 `Antialiasing` 的默认值为 `false`。

*   对于其他所有插值方法，默认值为 `true`。

**数据类型:**`logical`

返回索引图像的优化或原始颜色图，指定为以下值之一。

| 值 | 描述 |
| --- | --- |
| `"original"` | 输出颜色图 [`newmap`](https://ww2.mathworks.cn/help/matlab/ref/imresize.html#d127e789669) 与输入颜色图 [`map`](https://ww2.mathworks.cn/help/matlab/ref/imresize.html#d127e789060) 相同。 |
| `"optimized"` | `imresize` 返回新的优化颜色图。 |

`Colormap` 参量仅在调整索引图像大小时有效。

**数据类型:**`char` | `string`

执行颜色抖动，指定为 `true` 或 `false`。执行抖动时，会对图像应用一种噪声，以使量化误差随机化并防止出现大范围色块。

`Dither` 参量仅在调整索引图像大小时有效。

**数据类型:**`logical`

插值方法，指定为字符向量、字符串标量或二元素元胞数组。有关详细信息，请参阅 [`method`](https://ww2.mathworks.cn/help/matlab/ref/imresize.html#d127e789090)。

**数据类型:**`char` | `string` | `cell`

输出图像的大小，指定为由正数组成的二元素向量。有关详细信息，请参阅 [`[numrows numcols]`](https://ww2.mathworks.cn/help/matlab/ref/imresize.html#d127e788984)。

**数据类型:**`single` | `double` | `int8` | `int16` | `int32` | `int64` | `uint8` | `uint16` | `uint32` | `uint64`

_自 R2026a 起_

填充，指定为 `"symmetric"` 或 `"replicate"`。`imresize` 函数在执行插值之前应用填充。

| 值 | 描述 | 示例 |
| --- | --- | --- |
| `"symmetric"` | 添加的填充像素使其能够镜像图像的边缘。 | ![Image 9: Symmetric padded pixels reflect the pixel values across the boundary.](https://ww2.mathworks.cn/help/matlab/ref/image-padding-symmetric.png) |
| `"replicate"` | 所填充像素复制最邻近边界像素的值。 | ![Image 10: Replicate padding pixels have the same value as the nearest border pixel.](https://ww2.mathworks.cn/help/matlab/ref/image-padding-replicate.png) |

**数据类型:**`char` | `string`

大小调整缩放因子，指定为正数或由正数组成的二元素向量。如果指定标量，则 `imresize` 对行维度和列维度应用相同的缩放因子。如果指定二元素向量，则 `imresize` 对每个维度应用不同的缩放值。

如果您指定的大小调整缩放因子不会产生整数长度的图像维度，则 `imresize` 会在调整大小操作后调用 [`ceil`](https://ww2.mathworks.cn/help/matlab/ref/double.ceil.html) 函数。换句话说，输出图像有 `ceil(Scale(1)*size(A,1))` 行和 `ceil(Scale(2)*size(A,2))` 列。

**数据类型:**`single` | `double` | `int8` | `int16` | `int32` | `int64` | `uint8` | `uint16` | `uint32` | `uint64`

## 输出参量

全部折叠

调整大小后的图像，返回为与输入图像 [`A`](https://ww2.mathworks.cn/help/matlab/ref/imresize.html#d127e788881) 的数据类型相同的数值、逻辑或分类数组。

调整大小后的索引图像，返回为与输入索引图像 [`X`](https://ww2.mathworks.cn/help/matlab/ref/imresize.html#d127e789034) 的数据类型相同的数值数组。

调整大小后的索引图像 [`Y`](https://ww2.mathworks.cn/help/matlab/ref/imresize.html#mw_5fa09d46-c33a-4b30-8265-53e0356f1276) 的颜色图，以 _m_×3 数值矩阵形式返回。默认情况下，`imresize` 返回经过优化的新颜色图和已调整大小的图像。要返回与原始颜色图相同的颜色图，请使用 [`Colormap`](https://ww2.mathworks.cn/help/matlab/ref/imresize.html#d127e789311) 名称-值参量。

## 扩展功能

全部展开

用法说明和限制：

*   不支持用于索引图像的语法，包括名称-值参量 `Colormap` 和 `Dither`。

*   不支持自定义插值核。

*   所有名称-值参量都必须为编译时常量。

用法说明和限制：

*   不支持 `Colormap` 和 `Dither` 名称-值参量。

*   不支持索引图像。

*   不支持自定义插值核。

*   所有名称-值对组都必须为编译时常量。

*   对于某些插值核，MATLAB® 和生成代码之间的结果可能在数值上存在微小差异。

`imresize` 函数支持 GPU 数组输入，但有以下用法说明和限制：

*   `gpuArray` 输入必须为非稀疏数组。

*   不支持基础类型为 `categorical` 的 `gpuArray` 输入。

*   GPU 不支持索引图像。

*   如果使用双三次插值，输出图像可以有一些值稍微超出输入图像中的像素值范围。

*   在 CPU 和 GPU 上使用 `imresize` 的结果在数值上略有差异。这些差异出现在图像的右边界和下边界，肉眼几乎看不到。

有关详细信息，请参阅[在 GPU 上运行 MATLAB 函数](https://ww2.mathworks.cn/help/parallel-computing/run-matlab-functions-on-a-gpu.html) (Parallel Computing Toolbox)。
