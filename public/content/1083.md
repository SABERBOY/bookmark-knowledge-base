This section lists Emscripten’s public API, organised by header file. At a very high level it consists of:

*   [emscripten.h](https://emscripten.org/docs/api_reference/emscripten.h.html#emscripten-h): APIs for integrating with the browser environment.

*   [html5.h](https://emscripten.org/docs/api_reference/html5.h.html#html5-h): Low level glue bindings for interfacing with HTML5 APIs from native code.

*   [console.h](https://emscripten.org/docs/api_reference/console.h.html#console-h): Functions for writing to the console and stdout/stderr.

*   [preamble.js](https://emscripten.org/docs/api_reference/preamble.js.html#preamble-js): APIs for working with compiled code from JavaScript.

*   [File System API](https://emscripten.org/docs/api_reference/Filesystem-API.html#filesystem-api) (**library_fs.js**): APIs for managing file systems and synchronous file operations.

*   [Fetch API](https://emscripten.org/docs/api_reference/fetch.html#fetch-api): API for managing accesses to network XHR and IndexedDB.

*   [Wasm Workers API](https://emscripten.org/docs/api_reference/wasm_workers.html#wasm-workers-section): Enables writing multithreaded programs using a web-like API.

*   [Wasm Audio Worklets API](https://emscripten.org/docs/api_reference/wasm_audio_worklets.html#wasm-audio-worklets): Allows programs to implement audio processing nodes that run in a dedicated real-time audio processing thread context.

*   [Module object](https://emscripten.org/docs/api_reference/module.html#module): Global JavaScript object that can be used to control code execution and access exported methods.

*   [val.h](https://emscripten.org/docs/api_reference/val.h.html#val-h): Embind API to support transliteration of JavaScript code to C++.

*   [bind.h (under-construction)](https://emscripten.org/docs/api_reference/bind.h.html#bind-h): Embind API for binding C++ functions and classes so that they can be called from JavaScript in a natural way.

*   [trace.h](https://emscripten.org/docs/api_reference/trace.h.html#trace-h): A tracing API for doing memory usage analysis.

*   [fiber.h](https://emscripten.org/docs/api_reference/fiber.h.html#fiber-h): API for working with Fibers (co-operative threads)

*   [proxying.h](https://emscripten.org/docs/api_reference/proxying.h.html#proxying-h): API for synchronously or asynchronously proxying work to a target pthread.

*   [stack.h](https://emscripten.org/docs/api_reference/stack.h.html#stack-h): Inspecting the WebAssembly data stack.

*   [Advanced APIs](https://emscripten.org/docs/api_reference/advanced-apis.html#api-reference-advanced-apis): APIs for advanced users/core developers.
