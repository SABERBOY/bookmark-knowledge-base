Pots n Stuffs Mod (1.19.1, 1.18.2) – More Potion Effects
Pots n Stuffs Mod introduces into the game new unique potion effects that will be great assistance whenever players want to endeavor for their next adventures. While the game already provides numerous good potion effects such as Strength, Night Vision, and many others. Players would still run into different situations where these effects are inadequate to get through. With this in mind, Pots n Stuffs sets its own goal to create almost every single potion effect that players can possibly think of, in order to help them get through the game easier. Some prime examples of these effects are Photosynthesis, Inferno, Wakeup, and other more unique potion effects.
