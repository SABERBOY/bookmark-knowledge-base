HTML Language Code Reference
HTML Language Codes
HTML uses the ISO 639-1 language codes to specify the language of a web page.
A language code is a 2-letter abbreviation that specifies a language (for 
example 
en for English, 
no for Norwegian, and 
zh for Chinese). 
The language code is meant to assist search engines and browsers, and is 
specified in the 
lang attribute inside the 
<html> tag.
The following example specifies that the language of this web page is in English:
 <html lang="en">
...
</html>
Tip: See also: HTML Country Codes.
