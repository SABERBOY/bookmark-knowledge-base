Hi,
I use Rider IDE for coding. And I noticed that there is no available live templates for Entitas or I couldn't find it. So I've created code templates and want to share them. I attached the settings I use:
live-templates.jar.zip
To generate template codes use the abbreviations below and press TAB:
e_comp => Component
e_init => InitSystem
e_exec => ExecuteSystem
e_reactive => ReactiveSystem
e_feature => Feature
If anybody wants to use these templates, follow the instructions from Rider's official website: https://www.jetbrains.com/help/rider/Sharing_Live_Templates.html
Cheers
