Features
- No plugins or executables are required.
- Including a 2D layer inspector and complete 2D layer export to .pdf.
- Adjustable shell thickness.
- Input .OBJ, .BINVOX, .STL, .VOX (MagicaVoxel), .QB, .JPG, .JFIF, .WEBP, .GIF, .PNG and .BMP.
- Output, image sequence ( series of PNG images ), .OBJ (triangles or quadrilaterals), hexahedral, .XML, .JSON, .SCAD (OpenSCAD), .QB (Qubicle Voxel Editor), .BVX, MINECRAFT.JSON (minecraft), .GLB (binary GL Transmission Format), .SCHEMATIC (minecraft), .POV (povray), .PY, .VOX, .KVX, .JS, .TS, .PNG, .DAE, Cinema 4D python script, Avorion (sandbox multiplayer game), Blender python script, isometric pixel art and .STL.
- Greedy meshing, polygon reduction or mesh optimization if exported as single object.
