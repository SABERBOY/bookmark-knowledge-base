Kiwi Library (26.1.2, 1.20.1) – Make Modding No Longer Cumbersome
Kiwi Library is the shared code base behind Snownee’s mods, so most players install it because something else asked for it rather than for its own sake. It does carry a handful of small quality of life tweaks on top of that, such as showing item NBT and tags in tooltips and switching off Microsoft’s telemetry. For mod authors it is the more interesting half: a module system with annotations that registers blocks and items without the usual boilerplate.
Features:
- Acts as the shared library that Snownee’s mods load, which is why most packs include it.
- Item tooltips can show NBT data and tags, handy when debugging a pack or checking a recipe input.
- Microsoft’s telemetry reporting is switched off.
- A toggle silences toast notifications and their sounds when you need a quiet screen.
- The experimental world settings warning can be suppressed, though this is off until you ask for it.
- The fade effect on resource reload and on the main menu can be dropped, also off by default.
- Mod authors get a module and annotation system for registering blocks and items with far less code.
- A font renderer is included that handles line wrapping and hex colour better than the vanilla one.
- Builds exist for Fabric, Forge, NeoForge and Quilt.
How to Use:
- Install the loader you play on, then drop the Kiwi Library jar into .minecraft/mods.
- Add the mod that needed it alongside. On its own the library changes very little.
- Install Cloth Config as well if you want to change the settings from inside the game.
- Without Cloth Config, edit the file the mod writes into your config folder instead.
- Turn the tooltip and telemetry options on or off there to taste, then restart the game.
Commands:
- /kalc opens a small calculator you can use without leaving the game.
- /kiwic quiet mutes the toast notifications and sounds that are playing.
