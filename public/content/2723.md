ISO 639 is a standardized nomenclature used to classify languages.[1] Each language is assigned a two-letter (set 1) and three-letter lowercase abbreviation (sets 2–5).[2] Part 1 of the standard, ISO 639-1, defines the two-letter codes, and Part 3 (2007), ISO 639-3, defines the three-letter codes, aiming to cover all known natural languages, largely superseding the ISO 639-2[2] three-letter code standard.
