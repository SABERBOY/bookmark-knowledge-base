## [](https://blog.csdn.net/Mculover666/article/details/125646383)[](https://blog.csdn.net/Mculover666/article/details/125646383)一、问题描述

当使用git管理了一个大文件的时候，如果将该文件从 文件系统 删除之后再 commit 到仓库，这个时候仓库中依然有该文件的记录。

这样会导致. git仓库 一直比较大，所以，如果确保不会回退到之前的版本了，那么可以将该大文件彻底从提交记录中删除。

## [](https://blog.csdn.net/Mculover666/article/details/125646383)[](https://blog.csdn.net/Mculover666/article/details/125646383)二、解决方案

（1）查看当前5个大文件

```bash
git rev-list --objects --all | grep "$(git verify-pack -v .git/objects/pack/*.idx | sort -k 3 -n | tail -5 | awk '{print$1}')"
```
