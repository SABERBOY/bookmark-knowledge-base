### [](https://blog.csdn.net/baidu_40202612/article/details/118753587)[](https://blog.csdn.net/baidu_40202612/article/details/118753587)前言

> 在目前APP中，推送功能也是比较常见的，为了保证在应用关闭的情况下，用户依然能够接收到推送通知，这里详细介绍下iOS推送配置。

### [](https://blog.csdn.net/baidu_40202612/article/details/118753587)[](https://blog.csdn.net/baidu_40202612/article/details/118753587)创建App ID

访问 [苹果开发者网站](https://developer.apple.com/)，点击 Account 登陆进入账户页面。  
![Image 47: 在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/9d3bbfe30190c6ee0854a9b34b5262e7.png)  
 点击 Certificates, Identifiers & Profiles。

![Image 48: 在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/5e1fd44fdf03afb290905407a73adf3f.png)  
 点击左侧菜单栏 Identifiers，然后点击 + 。  
![Image 49: 在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/99d75f6046d9d471576d636d5b47a84c.png)  
 选中 App IDs，然后点击 Continue。  
![Image 50: 在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/1bef1320c2a076a7b776b598d8f78337.png)  
 填写 Description，选择 Explicit，并填写 Bundle ID。  
![Image 51: 在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/632df1ed78b30573b047642766572a8a.png)  
 在 Capabilities 中勾选 Push Notifications，然后点击 Continue。  
![Image 52: 在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/cb1242d046061ff4fa3cff30e9b1dae2.png)  
 确认信息并点击 Register。  
![Image 53: 在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/b60fad738fccc6196a256701131fbe60.png)

### [](https://blog.csdn.net/baidu_40202612/article/details/118753587)[](https://blog.csdn.net/baidu_40202612/article/details/118753587)创建推送证书

可以参考 [iOS制作证书](https://www.yd-mobile.cn/#/book?active=4&wd=iOSCer.html)

下方是快速创建过程，以开发证书为例（测试证书）：

开发 & 生产环境证书名为：Apple Push Services:xxx.xxx.xxx  
 开发环境证书名为：Apple Development IOS Push Services:xxx.xxx.xxx  
 点击左侧菜单栏 Identifiers，找到我们创建的 App ID ，点击进入。  
![Image 54: 在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/ada09b885d1733131875eab471445de6.png)  
 页面向下，找到 Push Notifications，点击 Configure ，点击进入。  
![Image 55: 在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/96ff017fb751629cc188ef0572e53b00.png)  
 点击 Create Certificate 创建证书。  
![Image 56: 在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/2ad6f1b92380f2dde355d89c1c93914b.png)  
 此处需要我们上传 Certificate Signing Request 文件，文件创建参考 [iOS制作证书-生成certSigningRequest文件](https://www.yd-mobile.cn/#/book?active=4&wd=iOSCer.html)，然后点击 Continue。  
![Image 57: 在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/9f19f9ded5abdf99f459bc410eb59c6d.png)  
 创建完成推送证书之后，点击 Download 下载到本地。  
![Image 58: 在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/e14c72121a5ea7733537c64ce670b38a.png)  
 下载到本地后，双击 cer 打开证书，将其安装到钥匙串，若弹出安装提示，选择安装到“登录”，在钥匙串中找到安装的证书，若提示此证书是由未知颁发机构签名的，请下载Apple Worldwide Developer Relations Certification Authority证书进行安装，地址： http://developer.apple.com/certificationauthority/AppleWWDRCA.cer 在左边选择"登录"和"我的证书"，找到证书，在证书上面点击鼠标右键，然后在菜单中选择导出证书，如图：  
![Image 59: 在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/209ee004e76c07e98bcebe2bef609d0a.png)  
 在弹出页面中指定证书名，点击"存储"。

![Image 60: 在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/683dac9a0bd179b164f6865cff73c9fd.png)  
 设置证书密码，密码随意设置，点击"好"，生成p12格式证书  
![Image 61: 在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/5e01f436e4d3e3df33a90242cdd34a49.png)  
 查看生成的p12证书  
![Image 62: 在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/3901e9da210ba0e56ac9ff1b6a04366d.png)
