Spectral.js is a lightweight library for realistic color mixing based on the Kubelka-Munk theory. It's designed specifically for developers and artists aiming to implement realistic pigment mixing in their projects.
Originally created by Ronald van Wijnen, this repository provides a straightforward port of the library for Unity.
Currently, it includes only an HLSL shader implementation. C# scripts are planned for a future update.
- Unity 6
Follow those instructions to set up the scoped registry. Then, you can install the Spectral.js for Unity package via Package Manager.
