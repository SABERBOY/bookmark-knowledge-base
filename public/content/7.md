```cobol
Cloning spec repo `cocoapods` from `https://github.com/CocoaPods/Specs.git`[!] Unable to add a source with url `https://github.com/CocoaPods/Specs.git` named `cocoapods`.You can try adding it manually in `/Users/fyhsurvivors/.cocoapods/repos` or via `pod repo add`.
```

AI代码解释

### [](https://blog.csdn.net/survivorsfyh/article/details/105654685)解决办法

首先，因 CocoaPods 的库文件较大[https://github.com/CocoaPods/Specs.git](https://links.jianshu.com/go?to=https%3A%2F%2Fgithub.com%2FCocoaPods%2FSpecs.git)的方式很容易中断，建议尝试切换为 ssh 的方式进行 clone 操作[git@github.com](https://links.jianshu.com/go?to=mailto%3Agit%40github.com):CocoaPods/Specs.git

其次，终端中输入如下命令，处理 cocoapods 的 repos；

```bash
rm -rf ~/.cocoapodsmkdir -p ~/.cocoapods/reposcd ~/.cocoapods/reposgit clone git@github.com:CocoaPods/Specs.git
```

AI代码解释

注：如上操 clone 时对网络环境要求较高

若成功，则可以尝试在对应的项目中执行 pod install 即可

![Image 43](https://i-blog.csdnimg.cn/blog_migrate/dd0bf2e7fd710416f5d464ad85279a80.png)
