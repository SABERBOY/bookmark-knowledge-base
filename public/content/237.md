## post by rafael_lima83 on Jul 19, 2024

I am doing a game where I need stuff to be drawn on screen with a certain priority. Right now I’m using 5 stacked cameras to get that… a “Base” one handled by Cinemachine and it shows the background, A camera for the enemies, a Camera for the player (which has to be shown above enemies), a camera for bullets (which have to be shown on top of everything and are actually 2D sprites), and a camera for the UI (Which uses Orthographic projection). The result of this is then rendered to a texture which I can show at the screen the way I want it.

I see this is the way it’s suggested by Unity documentation everywhere, and yet there’s a lot of documentation also saying how stacked cameras are an overhead, and I can see it on the profiler.

Is there any other way to do this which costs less time in a frame?

## post by IllTemperedTunas on Jul 19, 2024

I can’t gaurantee this would work but I would attempt to do this through shaders. Create the type of shader you require in shadergraph then set the depth test to always

[![Image 1: image](https://europe1.discourse-cdn.com/unity/original/4X/0/7/e/07ea7951e95aa282160ef584475e41ddb2dcc32a.png)](https://europe1.discourse-cdn.com/unity/original/4X/0/7/e/07ea7951e95aa282160ef584475e41ddb2dcc32a.png "image")

![Image 2: image](https://europe1.discourse-cdn.com/unity/original/4X/e/2/2/e2264ba78c9e50b196cfa21b41b452068fcf95e2.png)

Create unique materials for the player, enemies and projectiles, then in the render queue play with the values to define if they are rendered above or below others.

This MIGHT work, at the very least you can create just the projectile shader and set it to always and it will reduce one camera specifc sorting you’re doing by one instance. You can of course play with all these settings and see if you can pull it off through other means, like setting the shader of the assets you want in the background to “never”, but shaders are probably your best bet for a simple and performant solution without a lot of overhead.

Oh and bear in mind, if there are multiple enemies that you might want rendering above or below one another, you may want to set them to the standard rendering test mode without the above tunings then you could set the player to “always render”.

And as for particles you can do a lot with multiply shaders and additive shaders that don’t have the same sort of sorting issues.
