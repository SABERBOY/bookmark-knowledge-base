Blossom Mod (1.20.1, 1.19.4) – Getting Fruits from Trees
Blossom Mod makes oak leaves bloom and bear fruit! Now you don’t have to break the leaves to get an apple – just pick it when it’s ripe. Oak leaves will start blooming thanks to bee pollination, so make sure to keep some bees nearby. You can also speed up apple growth using bone meal.
Features:
- It adds a Flowering Oak Leaves block that Oak Leaves can turn into.
- These flowering leaves will grow until they bear fruit, which you can then shear to obtain! Upon shearing, these flowering leaves will return to normal leaves until they start the process over again.
Commands:
These are Blossom’s commands and what they control.
Config
- /blossom config reload
  - Reloads the config.
- /blossom config reset
  - Resets the config to its default values.
Query
- /blossom query exposed
  - Queries if leaves must be exposed to a non-solid block for bees to attempt to grow.
- /blossom query rate
  - Queries the tick rate of bee attempts to grow leaves to flowering leaves.
- /blossom query count
  - Queries the min-max count range of apples dropped upon shearing.
Set
- /blossom query exposed <value>
  - Sets if leaves must be exposed non-solid block for bees to attempt to grow.
    - value : A boolean value.
- /blossom set rate <value>
  - Sets the tick rate of bee attempts to grow leaves to flowering leaves.
    - value : An integer value of the distance the HUD is raised.
- /blossom set count <min> <max>
  - Sets the min-max count range of apples dropped upon shearing.
    - min : An integer value of the minimum count of the itemstack.
    - max : An integer value of the maximum count of the itemstack.
Config:
These are Blossom’s config options and what they control.
Exposed
If leaves must be exposed to a non-solid block for bees to attempt to grow. Set to either true or false.
Rate
tick rate of bee attempts to grow leaves to flowering leaves. Must be at least 1.
Count
A min-max count range of apples dropped upon shearing. Min must be between 0 and 64. Max must be between 1 and 64.
Default Config
Here is an example of the default config.
{
  "exposed": true,
  "rate": 5,
  "count": {
    "min": 2,
    "max": 4
  }
}
