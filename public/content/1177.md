Runs on NVIDIA RTX 30, 40 and 50 series (Windows and Linux), AMD Radeon AI PRO R9700 (Linux), AMD Ryzen AI Max — Strix Halo (Windows), and Apple Silicon Macs with 64 GB or more, text only (Mac). Setup downloads the files and the DeepSeek engine, then starts the model.
strata launch --family deepseek41 --model ist-das-2.00bpw --plan

Install commands
Linux / Mac
curl -fsSL https://github.com/Niko1221/Strata/releases/latest/download/install.sh -o install.sh && sh install.sh
Windows PowerShell
irm https://github.com/Niko1221/Strata/releases/latest/download/install.ps1 | iex
On Windows, open a new terminal afterwards. Then:
strata launch
Follow the prompts to download and start a model. Terminal guide.
