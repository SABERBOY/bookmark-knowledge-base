# patriciogonzalezvivo/lygia_unity_examples

This are HLSL examples of how to use LYGIA Shader Library on Unity. To use it make sure you clone this repository recursivelly. git clone --recursive https://github.com/patriciogonzalezvivo/lygia_unity_examples.git Or if you already clone it, make sure you clone the submodules as well git submodule init git submodule update git pull
