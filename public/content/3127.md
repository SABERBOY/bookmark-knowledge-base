一、购买VPS
搬瓦工和Dmit无疑是梯子界的王者。vps实时监控网：https://vpsoso.com 但需要根据自己的实力来购买。
1、线路选择（首选CN2GIA）
电信最好的出海线路是：CN2GIA，联通最好的出海线路是：9929，移动最好的出海线路是：CMIN2，其中，电信的CN2GIA最好，移动的CMIN2最次。
移动的根本问题在于，它的CMIN2超售严重，而且它狠起来，不仅跨网丢包（从电信到移动，或者联通到移动），就连自家的移动，省与省之间的移动传输也丢包。（因为移动的收益按省为单位来的）
所以，按理说，三网各自走自家的优化是最好的出海线路，但实际体验来说，三网都走CN2GIA，或者三网都走9929，表现也毫不逊色。
很便宜的vps走的就是动态路由，电信走163，联通走4837，移动走cmi，不仅延迟很高，而且存在大量丢包，尤其是晚高峰，卡到怀疑人生。
2、去程回程问题和大小包问题
最优质的是：不管是去程还是回程，都走最高端的线路，但有些商家，只是单程走高端线路，却故意不提，这点需要警惕。
还有个别商家，号称双程都走高端线路，但存在严重的大小包现象，实际上网体验不佳。

二、ssh连接VPS
1、最简单的是用cmd命令窗口
快捷键：windows+r，左下角出现窗口，输入：cmd，回车
然后输入：
ssh root@你服务器的ip -p 端口
回车，第一次回车以后需要输入：yes，再回车，提示让你输入密码，（注意：密码是不可见的，也就是说，你输入以后，你看不到，但其实输入进去了），最后就连接到服务器。
如果是macOS用户，打开终端，同样输入：
ssh root@你服务器的ip -p 端口
回车，第一次回车以后需要输入：yes，再回车，提示让你输入密码，（注意：密码是不可见的，也就是说，你输入以后，你看不到，但其实输入进去了），最后就连接到服务器。就连接到服务器。
2、用SSH工具
主流的有MobaXterm、finalshell等等。（以MobaXterm为列，其他SSH工具一模一样的流程，开源地址：https://github.com/RipplePiam/MobaXterm-Chinese-Simplified/releases ）
确认以后，会提示你输入密码，注意：密码是不可见的，你粘贴一次密码就行（注意：右键单击一次就是粘贴），然后回车。（别以为没粘上）
最后，就连上了服务器。
三、安装3x-ui面板的二种方式
1、指定版本安装（推荐）
在控制台输入：
VERSION=版本号 && bash <(curl -Ls "https://raw.githubusercontent.com/mhsanaei/3x-ui/$VERSION/install.sh") $VERSION
比如：v2.6.0（这个版本跟最新版本，最大的不同是，输出的url是http，而最新版本为ip加了ssl，所以协议是https，而https更安全）
VERSION=v2.6.0 && bash <(curl -Ls "https://raw.githubusercontent.com/mhsanaei/3x-ui/$VERSION/install.sh") $VERSION
（1）回车以后，等控制台一直输出，直到
Would you like to customize the Panel Port settings? (If not, a random port will be applied) [y/n]:
是否要自定义端口（这个端口是3x-ui面板的端口），输入 y，回车，
（2）Please set up the panel port:
输入你要设置的端口，注意，端口的范围是0 到 65535，建议五位数，比如10096，回车
（3）此时控制台会输出3x-ui面板的用户名、密码和访问面板的URL。
（4）将图中的Access URL复制粘贴到浏览器，同时输入用户名和密码，即可登录3x-ui面板。
2、最新版一键安装（UI界面再一次发生变化）
这样安装的是最新版，唯一的问题是，最新版可能存在bug（最新版v3与v2版本最大的不同是，它将客户端单独出来，配置完入站，再去配置客户端）。
在服务器的控制台输入：
bash <(curl -Ls https://raw.githubusercontent.com/mhsanaei/3x-ui/master/install.sh)
（1）回车以后，等控制台一直输出，直到
Would you like to customize the Panel Port settings? (If not, a random port will be applied) [y/n]:
是否要自定义端口（这个端口是3x-ui面板的端口），输入 y，回车，
（2）Please set up the panel port:
输入你要设置的端口，注意，端口的范围是0 到 65535，建议五位数，比如10096，回车
（3）Choose an option (default 2 for IP):
默认是2，意思是为是否ip加ssl证书，不用输入，直接回车
（4）Do you have an IPv6 address to include? (leave empty to skip):
是否要添加ipv6地址，默认留空是跳过。不用输入，直接回车
（5）Port to use for ACME HTTP-01 listener (default 80):
是否要使用80端口来监听证书验证，默认80.不用输入，直接回车。
（6）此时控制台会输出3x-ui面板的用户名、密码和访问面板的URL。
（7）将图中的Access URL复制粘贴到浏览器，同时输入用户名和密码，即可登录3x-ui面板。
