Pixabay Image Download Using Python AsyncIO
Introduction
Pixabay is a vibrant community of creatives, sharing copyright free images, videos and music. All contents are released under the Pixabay License, which makes them safe to use without asking for permission or giving credit to the artist - even for commercial purposes. That’s why Pixabay is my favorite image website and I could download the royalty-free images to do almost whatever I want for my personal usages and work.
In some scenarios, to distribute the images that I collected from Pixabay, instead of distributing the image files, distributing the computer program that allows the user to download the collected images from Pixabay is more effective. In this blog post, I would like to discuss how to download the Pixabay images in large scale using Python single-threaded AsyncIO and Pixabay API.
Pixabay AsyncIO Download
Collect Pixabay Image IDs
Each Pixabay image has a unique ID. We could collect the IDs as we browse the images from the Pixabay website. For example, the Pixabay image ID for the image bald eagle in the following URL is 6481346.
| 1 | https://pixabay.com/photos/bald-eagle-bird-raptor-bird-of-prey-6481346/ | 
It is possible to capture the Pixabay image URLs without using the Pixabay API. However, Pixabay will change the image URLs from time to time. Therefore, collecting Pixabay image URLs is not a good option for reproducibility.
Download Pixabay Images
Fortunately, we could query the Pixabay image URLs using the image ID via the Pixabay API.
To query and download the images asynchronously from Pixabay, we have to use aiohttp. To write files asynchronously to hard drive, we have to use aiofiles.
We created the following Python program to download the Pixabay images from image IDs.

| 1 2 3 4 5 6 | $ python download_async.py \ --image-ids-filepath pixabay_ids.txt \ --image-urls-filepath pixabay_urls.txt \ --download-dir pixabay \ --pixabay-api-key xxxxxxxx-xxxxxxxxxxxxxxxxxxxxxxxxx \ --update-image-urls |
