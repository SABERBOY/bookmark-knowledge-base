Odyssey, the most versatile 2d toolset
Combine the power of Unreal Engine with the spontaneity of drawing
Odyssey is primarly designed for the animation industry and other audiovisual production. Its numerous features free your creativity to make beautiful hybrid films and series for TV and theaters.
Who said Unreal Engine is not made for 2D games? With Odyssey enabled, you can definitely produce amazing 2D / 2.5D video games with animated cut-scenes, sprites and tiles directly created in the engine. You can even stylise your 3D game by adding 2D FX with Odyssey!
The ability to sketch and imagine new concepts thanks to Odyssey is a true asset for any industries that rely on visual arts, such as architecture, fashion, automotive or aeronautic.
Texture 2D assets can be created and edited with Odyssey into a dedicated interface to make stylized environments. Create dirt masks, wall graffiti, rain drops, foliages, grounds with seamless textures... Possibilities are endless with a drawing tool inside Unreal Engine!
You can directly paint over 3D Meshes using 3 different modes: Texture (based on the UV), Mesh and Screen (based on the point of view in the viewport). This is the best way to stylize your props and characters.
Odyssey offers hundreds of brushes (and you can download additional packs on Fab) with numerous different styles: crayon, paint brush, watercolor, grease pencil, speedlines, etc. Odyssey brushes are blueprint-based and are highly configurable and customizable.
Vector drawing tools offer a higher level of control over the lines and can use a library of indexed colors.
The interface has been entirely designed to ease the creative process for 2D artists, and still enjoy the power of a 3D real-time software. Even those who have never used Unreal Engine before can make great hand-drawn storyboards with Odyssey.
Importing image sequences to generate storyboard sequences, placing cameras and images in space, adding transform keys and edit timing, converting storyboard sequences into Level Sequences... Everything is done to ease the transition between the different production steps.
Odyssey includes features to turn your storyboard into an accurate and precise animatic, like adding sound tracks and displaying production notes or dialogues on screen. You want to add changes in some shots? Create takes to propose several variations!
Thanks to PDF and video export, sharing the work done with the rest of the production team will just be a mere formality.
2D animators can feel overwhelmed by Unreal Engine complexity: this is why Odyssey provides a specific interface. No 3D, just a timeline, a tool box, a canvas and a color selector: the bare necessities of (animators') life.
Adding 2D animations in a 3D environment is as simple as a drag and drop. Audacious 2D animators can enjoy the power of a 3D real-time environment thanks to the 2D timeline being embedded in the Sequencer. Interactions between 2D and 3D have never been easier, whether for character or for FX animation.
This powerful feature generates vector interpolations and imitates cut-out animation without rigs. This tools is terrific for quick animation tests and to teach the fundamentals of animation to students.
Light table (onion skin), shift and trace (out-of-pegs), cells mark, flip... All these usual features for traditional animation are included with Odyssey for artists' comfort.
Any assets created or edited with Odyssey are entirely compatible with Unreal Engine and can be used in runtime for various purposes, including 2D animated cut-scenes in video games. And it works the other way round, since you can customize assets from Fab with Odyssey!
Odyssey API is opened to allow any technical user to create widgets, customize rendering layouts or create brushes.
Odyssey is compatible with native Unreal Engine tools for revision control. Instead of using multiple software and sources, embrace a technology that gathers around 2D and 3D artists within the most collaborative and iterative software: Unreal Engine.
There are many plugins developed by other fellows (Paper ZD, Decal Designer) to be found on Fab that can be used in complement with Odyssey.
Odyssey used to be a stand-alone software powered by Unreal Engine between 2023 and 2025. Since June 2025, it is a plugin for Unreal Engine distributed on Fab that can be downloaded for free.

Odyssey requires Unreal Engine 5.6 minimum. 2D artists who work in the 2D editor only (no 3D viewport active) will need a minmum configuration of 16gb for the memory and a NVIDIA Quadro P1000 (or equivalent) for the GPU. For a hybrid usage with small / low-poly / unlit environments, a minimum of 32GB for the memory and a NVIDIA 1080 RTX (or equivalent) for the GPU is required. Odyssey works both on Windows and Mac OS.
