# keijiro/Voxelman: Unity ECS + C# Job System example

Voxelman is an example that shows how to use the new Entity Component System with Unity in an extreme way. Each voxel in the scene is instantiated as an entity, and controlled by component systems. It also utilizes the C# Job System, the Burst Compiler and the asynchronous raycast to hit the maximum efficiency of multi-core processors. - Unity 2022 LTS
