Voxelize volume data(.xraw) exported with MagicaVoxel in Unity
MagicaVoxel is a free lightweight 8-bit voxel editor and interactive path tracing renderer
(https://voxel.codeplex.com/)
- Type o xraw in MagicaVoxel command line to export volume data as .xraw file.
- import .xraw file in Unity Editor.
- Select Tool>irishoak>XRaw2PNGConvertor, and drag .xraw file into .xraw path column, then push Create button.
- save .png file in Editor.
- Change Texture format to RGBA 32bit
- Set PNG file to XRawDataTex in XRawVoxelManager.cs.
- Push TriggerSetXRawDataParams checkbox to set parameters.
- Push TriggerVoxelize checkbox to voxelize.
requires a graphics card that can support DX11
