## GoDaddy VPS 主机常见问题解答

### 什么是 VPS 主机，其优势如何？

虚拟专用服务器主机（VPS 主机）利用服务器虚拟化在由主机提供商管理的物理服务器上创建唯一、隔离的服务器空间。VPS 主机为用户提供高性能、隔离环境以及 CPU、RAM 和 100% 专用存储，不与任何其他网站或应用程序共享。由于 VPS 主机可以为用户提供专用资源，因此它的性能和安全性更高，灵活性更大，并且可以更好地控制服务器。

相较于共享主机，VPS 主机具有以下优势：

• 更高的资源配置与带宽/流量额度。  
• 加载速度更快，且提供无限流量。  
• 具备更高的安全管控权限。  
• 大幅降低遭受黑客攻击的风险。

与共享主机相比，VPS 可以让管理员更好地控制网站安全性，使其不容易受到黑客的攻击。如果使用共享主机，网站遭黑客攻击时，服务器上的其它网站很有可能也会遭受攻击。相反，由于虚拟隔离，同一硬件上遭黑客攻击的 VPS 不会影响周围的 VPS 环境。

有了根访问权限，您安装的应用程序将不受限制；您可以访问和编辑系统文件、设置和服务器登录。

### 最常见的专属 IP 用例是什么，每个套餐包含多少个 IP？

专属 IP 地址可用于自定义应用程序、暂存网站、电子邮件和其他管理任务。

*   **自定义软件和应用程序：**若您的服务器上运行着任何自定义软件，则可能需要一个独立 IP 地址。某些类型的服务器软件需要独立 IP 地址才能正常运行。
*   **电子邮件递送：**如果您使用域名云邮（如 mailto:myemail@mydomain.com），您可能会面临邮件投递受阻的风险。虽然并不常见，但当您将共享 IP 地址用于收发电子邮件，并且将同一共享 IP 用于其他用途时，您的 IP 被列入黑名单或被阻止的风险将增大。专属 IP 是保护您的声誉以及确保将您的所有电子邮件发送给预期收件人的一种很好的方式。
*   **控制面板管理：**将您的网站和控制面板分离到两个不同的 IP 地址上，以确保安全并隔离服务。

**其他 IP 地址（仅根据客户请求）**

*   基础档 – 不含额外 IP 地址
*   第档 – 含一个额外 IP 地址
*   其他所有档 – 含三个额外专属 IP 地址

## 处理信用卡的网站和应用都需要符合 PCI 标准

支付卡行业安全标准委员会（PCI-SSC）制定了保护信用卡数据的标准。也就是说，任何传输、处理或存储信用卡信息的企业都需要遵守 [支付卡行业数据安全标准](https://www.godaddy.com/zh-sg/help/-20226) 的相关标准。想要通过你的网站收款，你需要确保客户的支付信息安全，并且符合 PCI 的要求。为了简化流程，你可以在网站上集成像 PayPal Checkout、Square Online Checkout 和 Stripe Checkout 这样的第三方产品，帮你处理付款（这样信用卡数据就不会存储在你的主机服务器上）。记得了解更多额外要求，确保你的业务持续 PCI 合规。
