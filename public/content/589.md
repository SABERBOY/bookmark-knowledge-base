**Announcement:** The easy to remember URL for this site is **http://www.graphicsgems.org/**.

This is the official on-line repository for the code from the _Graphics Gems_ series of books (from [Academic Press](http://www.academicpress.com/)). This series focusses on short to medium length pieces of code which perform a wide variety of computer graphics related tasks. All code here can be used without restrictions. The code distributions here contain all known bug fixes and enhancements. We also provide errata listings for the text of each book. Please report any new errata or bugs to [Eric Haines](mailto:erich@acm.org). Better yet, submit a pull request to the **[Github repository](https://github.com/erich666/GraphicsGems)**.

The gems can be viewed **[by category](https://www.realtimerendering.com/resources/GraphicsGems/category.html)**, **[by book](https://www.realtimerendering.com/resources/GraphicsGems/gems.html)**, or **[by author](https://www.realtimerendering.com/resources/GraphicsGems/authors.html)**. Gems code can be accessed in a variety of ways: by viewing the code directly from these pages or by downloading the whole website or a book's entire code base. Best is probably downloading the code from **[Github](https://github.com/erich666/GraphicsGems)**.

**New:** you can search inside all the books on Amazon (though content is limited), and excerpts of many articles are available on Google Books. Links below.

Graphics Gems V: sampling patterns

There is also a bookmarked **[PDF version](https://www.realtimerendering.com/resources/GraphicsGems/allgemspdf.zip)** of all the gems, created by Guillermo Gallo. It is somewhat out of date (March 2001), but handy for viewing and searching the entire code distribution.

The "sampling patterns" are data files related to Robert Cross' Gem, **Sampling Patterns Optimized for Uniform Distribution of Edges**.

**Common code files:** the original GraphicsGems.h, GGVecLib.c, and GraphicsGems.c (which replaces GGVecLib.c) files are found in their book's related directories, as these vary from volume to volume. The common, maintained versions for all of these are found at the root [GraphicsGems.h](https://www.realtimerendering.com/resources/GraphicsGems/GraphicsGems.h) and [GraphicsGems.c](https://www.realtimerendering.com/resources/GraphicsGems/GraphicsGems.c) files.

**EULA:** The Graphics Gems code is copyright-protected. In other words, you cannot claim the text of the code as your own and resell it. Using the code is permitted in any program, product, or library, non-commercial or commercial. Giving credit is not required, though is a nice gesture. The code comes as-is, and if there are any flaws or problems with any Gems code, nobody involved with Gems - authors, editors, publishers, or webmasters - are to be held responsible. Basically, don't be a jerk, and remember that anything free comes with no guarantee.

**Related Resources:** The _Graphics Gems_ series has been ended by the founding editor, Andrew Glassner. To allow continued presentation of new results, he started the [_journal of graphics tools_](http://www.tandfonline.com/loi/ujgt21), a quarterly which includes Gems-like material and which has a free [code repository](https://github.com/erich666/jgt-code). This was then succeeded by the [_Journal of Computer Graphics Techniques_](http://jcgt.org/read.html?reload=1), an open-source journal in which many of the articles include code.

An excellent place for solid code for all sorts of basic graphics algorithms is Dave Eberly's [Geometric Tools](http://www.geometrictools.com/) site.

Another useful site is the [3D Object Intersection page](http://www.realtimerendering.com/int/). Gems and other articles about various intersection algorithms are shown here.

The [archive at Geometry Algorithms](http://www.geometryalgorithms.com/algorithms.htm) has a number of good articles on common geometric operations relevant to graphics.
