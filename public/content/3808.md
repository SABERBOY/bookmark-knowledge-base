## [Notes](http://www.unicode.org/Public/18.0.0/charts/)

To get a list of code charts for a character, enter its code in the search box at the top. To access a chart for a given block, click on its entry in the table. The charts are PDF files, and some of them may be very large. For frequent access to the same chart, right-click and save the file to your disk. For an interactive index of character names, use the [Unicode Character Names Index](http://www.unicode.org/charts/charindex.html).
